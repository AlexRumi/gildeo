# Gildeo

Control de horas, gildas y cobros semanales.

- Registra jornadas con cronómetro o a mano, con los tipos de gilda y los cubos.
- Semana de domingo a sábado, con el sábado como día de cobro.
- Resúmenes semanales y mensuales, que se pueden compartir como imagen.
- Copia de seguridad con aviso cada 7 días.

Los datos se guardan solo en el móvil donde se usa. Cada persona que la abra tiene sus propios datos.

## Publicar en GitHub Pages

1. Sube todos estos archivos a la raíz de un repositorio.
2. En el repositorio, ve a **Settings → Pages**.
3. En "Branch", elige `main` y la carpeta `/ (root)`, y pulsa **Save**.
4. Al cabo de un minuto, la app estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Actualizar

Cuando cambies algo, sube en `sw.js` el número de `VERSION` (por ejemplo, de `gildeo-v1` a `gildeo-v2`) para que los móviles cojan la versión nueva.
